# ZG-09: the Board's World view, five cards from csf.json

Floor ZG-09 of Site ZG (ZG Pour 1, size M, depends on ZG-05 and ZG-06). Branch `zg-09-world-view`, built 2026-10-23 (MT).
Repo brain-monitor; zeitgeistd is not touched. **Held, not merged:** it waits for Jordan's three design calls on the v3 mock
(`gemini-brain/projects/tide/design/tower-mock-v3-pixel-2026-10-23.html`).

## In plain words

The Board has a new **World** tab. It shows the lobe's frame (`csf.json`) as five pixel-RPG dialogue boxes: Charter, Open
loops, Signals, Decisions ready and Lobe health, under a small pixel lookout scene and a row of counts. Every card says what
fills it and which Pour builds it when it is empty. A missing, stale or refused frame is one plain line, never an error page.
Yard signal titles name work orders, so the phone only ever gets their count.

## What it does

- **Server (`pass-app/server.mjs`):** `lobeView()` reads `csf.json` only, read-only, from `ZEITGEISTD_HOME` (a leading `~`
  expands like Python's expanduser), else `<kitchen>\lobe`. It is memoized by `sigOf` like `leadView`, so one `stat` a pass
  and one read per change. No git, no child process, no model, no database. `GET /api/lobe` returns `{ok, csf, health}` or
  `{ok:false, why}` behind the same auth as every route. `state.lobe` carries the same value, so a new frame reaches open
  phones as a `patch` on `/api/stream` (the live pass runs every second).
  - Refused in fixed words, never echoing the file: over 2,400 characters (csf.py `MAX_CHARS`), not JSON, not the six
    document 6.2 sections in order, a folder, or a lobe home inside a protected path (handoff.ps1's list, as in ZG-08).
  - `2_endogenous_self_state.yard_signals` is replaced by its count before anything leaves the process.
- **View (`pass-app/public/lobe.js`, its own module):** `frameOf()` decides present, missing, stale or refused; `worldHtml()`
  builds the markup; `paintWorld()` draws the art. Stale = the older of compile age and sweep age is over 240 min (zeitgeistd
  `health.py`: 2 x every 120 min). A time more than 5 min in the future, or a `meta.state` / `meta.charter` the lobe never
  writes, is refused.
  - **Charter:** EXAMPLE badge until locked (LOCKED after), domain chips, objectives, hard guardrails.
  - **Open loops:** the questions as an RPG menu with the pixel cursor, "N of M open, heaviest first".
  - **Signals:** title, band badge, Signal / Fact / Hype / Surprise and source trust as 10-segment HP gauges (hype reads as a
    warning when high), "Who profits if you believe it", the 24 h count and the hype held back.
  - **Decisions ready:** the id and the A / B steelmen as a choice menu, marked Needs sign-off and read-only (the tap is
    ZG-25), post-mortems due.
  - **Lobe health:** fresh in green or "No sweep yet" in red with the reason, a freshness gauge, last sweep, compiled, frame
    size, 24 h counts, Yard events as a count.
- **Look:** original pixel art in the sprites.js format (palette-indexed strings, warm outline `a`, light from the top left):
  five 16x16 card icons, the menu cursor and the double-framed dialogue box from the v3 mock, a 12x12 globe for the World
  tab (plain, lit and dark, like the other tab icons), and a 160x40 lookout scene: sky by the hour (sprites.js `SKIES` and
  tint), far mountains, hills, a radio mast with one gold ring per world signal (max 3), an A / B signpost, and a lookout tower
  whose window and lantern are lit only while the frame is fresh, flying a gold flag (EXAMPLE) or a green one (LOCKED). The
  sun, moon and lantern are sprites.js's own. Drawn once into CSS variables (`--lobe-*`, `--px-tab-world`); no animation
  loop. The only motion is the menu cursor's 2-step nudge, off under `prefers-reduced-motion`.
- **Hooks:** `app.js` (import, `world: 'World'` in TITLES, one render line, `renderWorld`, one start-up paint call),
  `index.html` (the nav link, its fallback SVG symbol, the view section), `sw.js` (`/lobe.js` in the offline shell, which
  Test-PassApp requires of every script), `app.css` (one block at the end; the bar grid gains a sixth column).

## Decisions (each a choice, not a guess)

- **csf.json only.** The Blueprint's ZG09-1 also names `watch\lobe.json` (ZG-06's heartbeat) for the health card. This
  build reads csf.json only, as instructed. So breakers, the DLQ and skipped runs are not on the card; it says where they
  live (ZG-06) and which card shows them (ZG-30, ZG Pour 4).
- **Missing, stale or refused = one plain line**, no cards. ZG09-2's "a stale or skipped lobe shows red with the reason" is
  met by that line (red) and by the health card's red "No sweep yet" for an empty frame.
- **Counts only for Yard signals**, stripped on the server and counted again in the view. The rest of the frame is shown
  whole (the Board is tailnet-only).
- **Staleness is judged on the phone** from the frame's own times, re-checked when the minute turns and the view redraws.
