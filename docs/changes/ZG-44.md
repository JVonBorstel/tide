# ZG-44: the switch: NOW and the Shift handover from the lobe's frame, behind Jordan's flag, the files kept as the mirror

Floor ZG-44 of Site ZG (size S). Depends on ZG-43 (zeitgeistd: FRAME.md, the cloud-safe twin) and ZG-08 (brain-monitor: the
World & self section). Branch `zg-44-boot-switch`, built 2026-10-24. Repo brain-monitor. zeitgeistd is not touched.

## In plain words

Every new Claude session starts by reading the Toolbox talk (`memory/BOOT.md`). Today its "NOW" part is the first 25 lines of
`memory/NOW.md`, and its Shift handover is `memory/PICKUP.md`. This Floor adds a switch. When Jordan turns it on, those two parts come
from the lobe's frame (`FRAME.md`, the cloud-safe twin of `csf-brief.json`) instead. NOW.md and PICKUP.md stay where they are as the
mirror. Nothing deletes or rewrites them.

**The switch ships OFF, and it is not flipped on this PC.** With it off, the Toolbox talk is byte-for-byte what it was before this
Floor. A test checks that.

## The flag (Jordan's tap, Q14)

`kitchen.json`: `"lobe": {"briefFromFrame": true}`. The state-folder copy (`<kitchen>\kitchen.json`) is read first, then this repo's
`kitchen/kitchen.json`. The first one that has the key decides. Only a JSON `true` turns it on. `"true"` as a string, `false`, a missing
key, or an unreadable kitchen.json all count as off. This repo's kitchen.json does not have the key (a test checks that).

## With the flag on

The frame is used only when every condition below holds. They are checked in this order, and the first one that fails is the one named.

1. `csf-brief.json` passes ZG-08's checks: cloud-safe keys only, no secret shapes, no links or identifiers, not the home-folder name,
   ASCII, 2,400 bytes at most. It was also compiled under 2 h ago.
2. `FRAME.md` is in the same lobe home (`ZEITGEISTD_HOME`, else `<kitchen>\lobe`). It is a file, 8,000 bytes at most, plain ASCII and
   39 lines at most. Its first line is `# FRAME`, and line 3 has a compiled time under 2 h old that is not in the future. Every line
   passes the same text checks as the brief.
3. `<kitchen>\watch\memory.json` (memory-truth.ps1) ran under 2 h ago, and its drift count (`found`) is 0.

Then:
- **state:** the live lines stay as they are (main status, the Yard, phone alerts, work orders, site check). They are read from files at
  build time. The heading becomes `## Current state (working memory: the lobe's frame, FRAME.md; memory/NOW.md and memory/PICKUP.md are
  the mirror)`.
- **now:** `## NOW (first 25 lines of the lobe's FRAME.md, compiled N min ago; memory/NOW.md is the mirror)`, then one line giving
  NOW.md's last-changed time, then FRAME.md's first 25 lines.
- **pickup:** `## Shift handover (the frame's last-session node, compiled N min ago)`, then the `## Last session` line(s) from FRAME.md,
  then one pointer line: `Full note: memory/PICKUP.md (the mirror, written N h ago; never deleted or written by this script)`. Under brief
  option A, the frame has no last session. The Shift handover then stays on PICKUP.md, and its heading says why.

If any condition fails, the files are used as today. Each of the three headings carries `frame not used: <condition>` in fixed words,
for example `drift 2 in watch\memory.json`, `FRAME.md is missing`, or `csf-brief.json is 180 min old, over 120`. The talk is always
written. It never boots with nothing.

These parts are not changed: Jordan's notes, the Creed, the World & self section (ZG-08), approvals, active jobs, agent sessions and
repos. The budgets, the shrink order, the 10,000-char cap and the secret gate are not changed either. FRAME.md lines go through the
pack's `Clip` and secret gate like every other line.

## Hooks (ZG44-2)

`scripts/boot-inject.ps1` (SessionStart) and `scripts/refresh-boot.ps1` (PreCompact) are not changed. They read and rebuild BOOT.md as
before. A test feeds a frame-built pack to boot-inject, and it loads with its secret scan passing.

## Migration path (ZG44-3)

1. **Section (ZG-08):** the Toolbox talk shows the frame's cloud-safe brief as one section beside the files.
2. **Mirror and diff (ZG-43):** zeitgeistd writes FRAME.md, and `--diff` measures drift between the graph and NOW.md / PICKUP.md.
3. **Switch (this Floor):** behind Jordan's flag, NOW and the Shift handover come from FRAME.md when the frame is fresh and drift is 0.
   Otherwise the talk falls back to the files and says why.
4. **Files as mirror only:** once the frame has proven itself (the 14-day zero-drift measure), the files are only read as the mirror.

NOW.md and PICKUP.md are never deleted or rewritten by this script, at any step. A test checks their bytes and their write time after
a frame-built run.

## Decisions (each a choice, not a guess)

- **"drift" = memory.json's `found`.** memory-truth.ps1 writes no `drift` key. `found` is its count of drifts (its output says
  "N drift(s)").
- **The drift check must itself be under 2 h old** (2 x its `everyMin` 60). An old zero is not a zero now. This condition is not in
  ZG44-1's list. It errs toward the files.
- **FRAME.md must also be under 2 h old by its own compiled line.** Without this, a fresh brief could sit beside an old FRAME.md.
- **"state from the frame" = the state heading says working memory is the frame.** The state lines (main status, the Yard, alerts,
  work orders, site check) are read from live files when the talk is built. They are not memory prose, so they stay. Replacing them with
  frame lines would drop a red main from the talk.
- **The World & self section stays when the switch is on.** ZG44-2 asks that sections other than state, now and pickup be unchanged.
  It repeats some FRAME.md lines (Charter, world), and the shrink order handles the cost.
- **The switch is one block at the end, which rewrites the sections already built.** The byte-for-byte test can then strip it and
  compare, now and after any later change to the script. NOW.md and PICKUP.md are still read on the frame path. Reading is how the
  mirror is used. They are never written.
