## What it does

`scripts/memory-truth.ps1` has a fifth check, after the four it had:

- **Reads `<kitchen>\lobe\tensions.json`** (ZG-37's file: `[{id, subject, a:{value, source, at, ...}, b:{...}, since, weight, reviewed}]`).
  It only reads it; the test compares its bytes before and after a run.
- **Each tension is a drift finding** (ZG38-1), filed under the older side's memory file:
  `memory disagrees with itself: <subject> = 47 (a.md:7) vs 52 (b.md:9), since 2026-01-03; a proof or the Owner's decision settles it
  (lobe tension <id>)`. Both sources are named as `file:line` (ZG-37's `at`); a side with no `at` names its `source`. A tension the
  Owner marked "unknown" (REVIEWED) is still drift and says "the Owner looked and said unknown", since only a proof or an a/b decision
  settles it. Findings also carry `source: lobe`, `tension`, `a` and `b` for the Board. Exit 3 for drift is kept.
- **No file**: one line, `lobe: no tensions file`. Not a failure, not a finding (the lobe has not run yet).
- **A damaged file** (not JSON, empty, or not a list) is one drift finding on `lobe\tensions.json`: "the lobe's tensions file is
  damaged (<why>), so whether memory contradicts itself is unknown". Never read as "no tensions".
- **Entries that cannot be read** (no subject, a side missing, a side with no source) are counted in one finding that says so; the
  readable ones are still reported.
- **Text from the file is cleaned**: control and bidi characters become spaces; a subject is cut at 120 characters, a value at 60.
- **`unproven`** (ZG38-2): the WARN count (fact bullets with no proof and no "unknown") is written to `watch\memory.json` as `unproven`,
  next to the old `warn` (kept for the readers that use it, such as ZG-39's trust.py). The heartbeat also gets `tensions` (the count)
  and `lobe` (`absent`, `read` or `damaged`). `-Json` output gets `unproven` and a `lobe` block with a one-line summary.

The Yard's doctor already turns memory-truth's findings into a Watch alert (kitchen/kitchen.ps1, the watcher list), and alerts only
when the set of findings changes. So a new contradiction in memory alerts once, at the next run.
