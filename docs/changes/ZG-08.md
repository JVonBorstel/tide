# ZG-08: the Foreman's toolbox talk carries the lobe's frame (handoff.ps1 section)

Floor ZG-08 of Site ZG (ZG Pour 1, size S, depends on ZG-05). Branch `zg-08-brief-frame`, built 2026-10-23 (MT).
Repo brain-monitor; zeitgeistd is not touched.

## In plain words

Every new Claude session starts by reading the toolbox talk (`memory/BOOT.md`). It now has a short "World & self" part
with the lobe's frame: Charter domains, decisions ready, public world signals, counts and the trust line. It reads only
`csf-brief.json`, the cloud-safe extract zeitgeistd writes (ZG-05). The full frame (`csf.json`, `csf.lkg.json`) holds
personal data and is never opened, because the talk goes into a cloud session. When there is no frame, or it is stale,
or it fails a check, the talk shows one plain line instead, and the talk is always written.

## What it does

- **Where:** a new section right after `## Current state` and before `## Approvals` (INTEGRATION-MAP 5.1 step 1).
- **Path:** `ZEITGEISTD_HOME\csf-brief.json` when that variable is set (a leading `~` expands like Python's expanduser),
  else `<kitchen>\lobe\csf-brief.json`, where `<kitchen>` is the same folder the talk already uses (`BRAIN_KITCHEN`, else
  `%LOCALAPPDATA%\brain-kitchen`). A lobe home inside a protected path is refused and not read.
- **Present:** heading `## World & self (lobe csf-brief.json, N min old)`, N from the brief's `compiled_utc`. Then, most
  useful first: `Frame:` (state, Charter EXAMPLE or LOCKED, brief option, last sweep), `Counts:`, `Trust:`,
  `Decisions ready:`, the Charter lines, up to 5 world signals with scores and trust. Under option B it adds open loops
  and blind spots.
- **Missing:** one line, `lobe: no frame yet`. It never falls back to `csf.json` or `csf.lkg.json`.
- **Stale (older than 24 h):** heading `## STALE: World & self (lobe csf-brief.json, N min old): over 24 h old, treat as
  history`. The contents stay, under that heading.
- **Refused:** one line, `lobe: frame refused (<reason>)`. The reason is in fixed words and never echoes brief text.
  Reasons: over 2,400 bytes, not plain ASCII, not valid JSON, not a JSON object, a key outside the cloud-safe list
  (csf.py `BRIEF_KEYS`), kind is not `csf-brief`, no valid `compiled_utc`, compiled more than 5 minutes in the future,
  secret-shaped text (the pack's own `secret-patterns.ps1`, pattern name only), a link or identifier (zeitgeistd's own
  `IDENTIFIER_PATTERNS` from csf.py: url, email, path, handle, phone), the home-folder name, the brief is a folder,
  the lobe home is protected, or it could not be read (exception type only).
- **Budget:** the section has its own 900-char budget (Begin 900 'frame'). `Current state` keeps its 2150
  (TD-EH-03a/04). Every line goes through the pack's `Clip` (control, bidi and zero-width characters removed; 400-char cap;
  each value has a smaller cap of its own).
- **Shrink order:** over the 10,000-char cap the frame gives after NOW (both steps), agent sessions and repos, and before
  approvals, state, pick-up and notes. The Creed is still never cut.
- JSON is read with System.Text.Json, so time strings stay strings (ConvertFrom-Json would turn them into DateTime).

## Decisions (each a choice, not a guess)

- **A secret-shaped brief is refused inside the section; the pack is still written.** ZG08-2 says such a brief makes
  boot-inject refuse the pack. Jordan's rule for this Floor is "never break the talk", and letting the line through would
  make handoff.ps1's own gate delete BOOT.md (exit 2). So the reader refuses the frame in one line and the secret never
  reaches BOOT.md. boot-inject's scan is unchanged and a test proves it still refuses a pack whose frame line is
  secret-shaped.
- **Redact terms are not re-read.** The reader uses `csf-brief.json` only, so it does not open the lobe's `config.json`
  for `csf.redact_terms`. zeitgeistd's compile already refuses a brief holding one (ZG-05 guard). The reader re-checks
  what it can without other files: secret shapes, the identifier patterns and the home-folder name.
- **Stale = 24 h by the brief's own `compiled_utc`**, not the file time, matching ZG08-1's "N min old".
- **Shrink position:** after both NOW steps, agent sessions and repos. ZG08-3 says "after NOW and agents"; the frame
  sits above repos in the pack, so repos give first.
- **Missing is exactly one line, with no heading**, as ZG08-1 words it.
