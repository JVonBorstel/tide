# ZG-17: the morning card's World line, and a phone push with counts only

Floor ZG-17 of Site ZG (size S, depends on ZG-13 and ZG-07). Branch `zg-17-morning-line`, built 2026-10-24 (MT) on top of ZG-30's
branch (`zg-30-glass-box`, PR #104, which sits on #102 and #92). It merges after #92, #102 and #104.

## In plain words

- **The Board's morning card** shows one line: `World: 2 decisions ready, 1 question, 14 signals since yesterday; sweeps skipped 3x (RAM)`.
  A zero count says nothing, and when every count is zero there is no line. A missing or stale frame still shows ZG-13's red
  "Lobe: skipped, <why>" line.
- **The phone** gets the same words once a day at most, after the lobe's nightly rem run, and only when the counts changed since the last
  push. Numbers and fixed words only: never a title, a link, a source name, a loop's text or a skip's reason.
- **Push is off on this PC** (no `push-on` file). Then `notify.ps1` answers `off` and nothing is written or sent; the Step records nothing,
  so the first day push is on still gets its line.

## What it does

- **`kitchen/stations/lobe.ps1`** (the lobe Step):
  - A gate or lock skip (exit 11) is counted by kind: `ram`, `ollama` or `gpu`, in `<kitchen>\lobe\yard-counts.json`
    (`{skips: [{at, cmd, kind}], push: {line, at}}`, temp and rename, lines older than 48 h dropped). A refusal (exit 1, an Ollama
    address off this PC) is a failure, not a skip, and is not counted. The reason text never goes in the file.
  - After a rem run that exited 0 (`Send-LobePush`): counts from `<lobe home>\csf.json` (`decisions_ready`, `world_signals_24h`) only while
    the frame is fresh (240 min and `state: ok`, the Board's rule), plus the skips of the last 24 h. It builds the World line
    (`Format-WorldLine`), checks every word against a fixed list, and calls `kitchen/notify.ps1 -Level INFO -Text <line> -Safe`.
    Not sent: every count zero, a push already went out today (local date), or the line equals the last push's line. Only `sent: ok`
    is recorded. The push line never changes the run's exit or its done line (the spec's mustMatch).
- **`pass-app/public/world-line.js`** (new, pure): `worldLine(lobe)` gives the same words as `Format-WorldLine`. Only whole positive
  numbers count; anything else says nothing.
- **`pass-app/public/app.js`**: the brief shows the World line (escaped, `hot` when a decision is ready, an Open link to the World tab).
  ZG-13's red line shows only when `brief().lobe.skipped` is set. **`sw.js`**: `/world-line.js` is in the offline shell.
- **`pass-app/server.mjs`**, a minimal hook (ZG-25 owns this file): `brief()` gains `lobeSkips` from `lobeSkips()`, a 7-line function after
  `lobeBrief()`. It reads `yard-counts.json` (64 KB cap) and returns numbers only, `{sweep, rem, ram, ollama, gpu}` for the last 24 h, or
  `null` when there is no readable file. `brief().lobe` keeps ZG-13's exact shape (test-lobe.mjs pins its keys).

## Decisions (each a choice, not a guess)

- **State in `<kitchen>\lobe\yard-counts.json`, not `watch\lobe.json`** as the acceptance line says. The lobe's `health.beat` rewrites
  `watch\lobe.json` whole on every run and keeps only `spotchecks` (zeitgeistd `health.py` `beat`), so a key the Step put there would be
  gone after the next sweep, and "once a day" would fail. The Watch reads every `watch\*.json` as a heartbeat, so a second file there would
  be read as a broken one.
- **`notify.ps1 -Safe` does not strip content**: it sends the caller's text as given (cut at 200 characters). The Step makes the text
  safe itself: numbers and fixed words, checked against a fixed word list before the call, and the test proves it.
- **"1 question"** (calibration questions) shows on the Board when the frame has the count. It has none until ZG-27, so the server sends
  `null` and nothing is said. The push leaves it out for the same reason.
- **Skip words:** `RAM`, `Ollama`, `graphics card` (the Step's own message for a busy GPU lock), most frequent first. `sweeps` when only
  sweeps were skipped, `rem runs` when only rem, `runs` for both.
- **"Since yesterday"** is the last 24 h, the frame's `world_signals_24h` and the skips' own times.

## Unknown or not verified

- How the line looks on a real phone: not opened in a browser in this build (markup checks only; it reuses the brief's existing `li`,
  `hot` and `text-btn` classes, no new CSS). The live Board on 7878 was not touched.
- Two Step runs that skip at the same moment could each read the file before the other writes, and one skip would not be counted. The
  Yard's standing orders run sweep and rem hours apart.
- Per-PR CI (`ci.yml`, ubuntu) runs no Windows suite; see the PR for its result.
